# CADETE TRAVEL & TOURS — Website de Reservas

## O que está incluído
- Página inicial inspirada no modelo enviado.
- Design responsivo para computador, tablet e telemóvel.
- Reserva de Hotel.
- Pedido de Transfer.
- Hotel + Transfer.
- Tour / Pacote.
- Formulário com nome, telefone, e-mail, destino, datas, pessoas e observações.
- Botão de WhatsApp que monta automaticamente o pedido de reserva.
- Português / Inglês.
- Secções de serviços, destinos, corporate, sobre nós e contactos.

## Como abrir
Abra o ficheiro `index.html` no Google Chrome, Edge ou Firefox.

## Como publicar
Pode colocar os três ficheiros (`index.html`, `styles.css` e `script.js`) num alojamento web/cPanel. Depois, ligar o seu domínio, por exemplo:
`www.cadetetravel.co.mz`

## Importante
Este primeiro modelo envia o pedido pelo WhatsApp. Para ter:
- disponibilidade real de hotéis,
- preços automáticos,
- pagamento online,
- confirmação automática,
- painel administrativo,
- base de dados de clientes e reservas,

será necessário ligar o site a um sistema/backend de reservas.
